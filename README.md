# LUNA VPN

Начальная версия проекта: адаптивный сайт, демонстрационный кабинет / Telegram Mini App, Python-бот и общий backend. Выбранный дизайн: графит, серебро, фиолетовый свет, CGI-портал и живая 3D-сцена. На устройствах без WebGL включается сцена из CSS 3D-слоёв. Учитывается настройка уменьшения движения.

## Что готово

- `web/`: статический сайт, тарифы 390 / 1 080 / 4 200 ₽, локации, инструкции и модальные окна. Цены предварительные, платежи на сайте отключены.
- `web/app/`: Mini App с проверкой Telegram-подписи на backend. В обычном браузере показывает демонстрационный режим без выдуманной подписки.
- `backend/luna/bot.py`: «Купить VPN», «Моя подписка», «Выбрать сервер», «Инструкция», «Поддержка», кнопка кабинета после настройки.
- Оплата в Telegram Stars, проверка суммы/валюты/плательщика, защита от повторного учёта платежа, /paysupport, возврат администратором.
- Выдача и продление доступа администратором. У каждого заказа отдельное состояние. Бот и Mini App используют одну базу.
- SQLite для первого небольшого запуска. Переход к PostgreSQL и интеграция с панелью — следующий этап.
- Docker Compose и GitHub Actions для сайта и проверок backend.
- Сайт можно добавить на домашний экран как PWA. Он управляет доступом, но сам VPN-туннель не создаёт.

## Чего требует запуск

Для первого запуска бота и кабинета: домашний ПК, Python, бот BotFather с токеном, контакт поддержки и HTTPS-адрес для Mini App. Для реального VPN отдельно нужен проверенный поставщик доступа или собственный VPN-узел с панелью. Автоматическая выдача/отзыв ключей через API поставщика **ещё не подключены**. Пользователь устанавливает Happ / Incy и импортирует личную ссылку. Сайт на GitHub Pages не запускает Python-бота, базу и VPN.

Сейчас `SALES_ENABLED=false`. Не включайте продажи до проверки узлов, профиля, правил сервиса, возвратов и контакта поддержки. Заготовка не проверялась с реальным токеном или оплатой.

## Домашний Windows-сервер: запуск без Docker

Установите Python 3.12 или новее. Дважды нажмите `INSTALL_WINDOWS.cmd`, заполните `BOT_TOKEN` и `SUPPORT_USERNAME` в открывшемся `.env`, затем нажмите `START_LUNA.cmd`. Установщик не перезаписывает существующий `.env`. Бот и backend работают на домашнем ПК, база — в `data/luna.sqlite3`. Одно окно показывает ошибки и останавливает оба процесса по Ctrl+C.

Для рабочего Mini App настройте HTTPS-адрес и `MINI_APP_URL`. Сайт для просмотра дизайна публикуется на бесплатном GitHub Pages. Полный порядок: [docs/HOME_WINDOWS.md](docs/HOME_WINDOWS.md). Docker Desktop для этого варианта не нужен.

## Локальный запуск на Linux / macOS

Требуется Python 3.12. Из корня проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements-dev.txt
export PYTHONPATH="$PWD/backend"
export WEB_ROOT="$PWD/web"
export DATABASE_PATH="$PWD/data/luna.sqlite3"
uvicorn luna.api:app --host 127.0.0.1 --port 8000 --no-access-log
```

Откройте `http://127.0.0.1:8000/`. Без токена доступна витрина и демо кабинета; рабочая авторизация Mini App невозможна. Для запуска бота во втором терминале задайте `BOT_TOKEN`, `ADMIN_IDS`, `SUPPORT_USERNAME`, затем `python -m luna.bot`. Файл `.env` автоматически не подгружается при локальном запуске: переменные необходимо экспортировать самостоятельно. Не вставляйте токен в исходный код.

## Запуск на CORE

1. Скопируйте `.env.example` в `.env` и заполните **на сервере**. Токен не передавайте в чат, GitHub или публичный config.js.
2. Укажите `ADMIN_IDS` (Telegram user ID, не username) и `SUPPORT_USERNAME`.
3. Выполните `docker compose up -d --build`. API слушает только `127.0.0.1:8000`. Бот использует long polling, webhook ему не нужен.
4. Настройте HTTPS reverse proxy на CORE. Пример `docs/Caddyfile.example`; домен подставляется после покупки. HTTPS нужен Mini App и публичному backend.
5. Укажите `MINI_APP_URL=https://ваш-домен/app/`. Если сайт размещён отдельно, в `web/config.js` задайте `apiBase` с HTTPS-адресом CORE, а в `ALLOWED_ORIGINS` — точный origin сайта. Если backend и web на одном домене, `apiBase` оставьте пустым.
6. В `web/config.js` укажите **публичные** botUsername и supportUsername. Токен там запрещён.
7. В BotFather настройте Menu Button / Mini App на тот же HTTPS-адрес. Бот также установит кнопку кабинета при запуске с MINI_APP_URL.
8. Настройте Remnawave или выбранную панель отдельно, создайте узел и подписку. Панель не входит в этот Compose и не должна быть открыта без ограничений доступа.
9. Проверьте iPhone и Android в нескольких целевых сетях, выдачу, продление, отзыв, бэкап и восстановление. Затем настраивайте Stars.

## Команды администратора

В личном чате бота:

- `/id` — узнать свой Telegram ID.
- `/grant USER_ID 30 https://subscription.example/секрет` — выдать тестовый/бесплатный доступ, если нет ожидающего оплаченного заказа.
- `/grant USER_ID 30 https://subscription.example/секрет ORDER_ID` — исполнить конкретный оплаченный заказ. ID заказа приходит администратору после оплаты. Повторная выдача того же заказа отклоняется. 30 дней добавляются к будущей дате окончания действующего доступа, иначе к текущему времени.
- `/revoke USER_ID` — удалить доступ из кабинета. **Отдельно отзовите ключ в VPN-панели.**
- `/refund ORDER_ID` — провести реальный возврат Stars. Используйте только для согласованного возврата. Команда сама не меняет срок в панели и не отзывает VPN. После возврата скорректируйте доступ с учётом остальных покупок пользователя.

Перед `/grant` создайте/продлите профиль в панели на соответствующий срок и установите лимиты. Срок в базе бота сам по себе не останавливает рабочий VPN-ключ. Секретная ссылка остаётся в базе CORE и пересылается своему владельцу; доступ к серверу и копиям нужно ограничить. Журналы приложения не печатают токен и ссылку. Администратор вводит /grant в Telegram, что также передаёт ссылку платформе Telegram.

## Stars

Задайте положительный `STARS_MONTHLY_PRICE`, ссылки `TERMS_URL`/`PRIVACY_URL`, поддержку и ADMIN_IDS, только затем `SALES_ENABLED=true`. Значение Stars нельзя автоматически считать эквивалентом 390 ₽. Сумму, правила получения выплат и экономику проверьте отдельно. Оплата разовая за 30 дней, автоматического списания нет. Встроенной внешней оплаты цифрового доступа в Telegram нет.

При получении успешной оплаты заказ фиксируется и попадает администратору. На этой стадии доступ выдаёт человек. Уведомления повторяются до доставки; редкий дубль сообщения возможен при сбое после отправки, повторное зачисление оплаты предотвращается идентификатором платежа. Во время ручной выдачи регулярно контролируйте ожидающие заказы.

## GitHub и домен

Репозиторий проекта: https://github.com/appletube8-dotcom/Luna-vpn

1. В Settings → Pages выберите Source: GitHub Actions. Workflow публикует только `web/`.
2. В Actions запустите `LUNA website` кнопкой Run workflow, если после включения Pages нет успешной публикации.
3. Фактический адрес опубликованного сайта появится в Settings → Pages → Visit site. Пока workflow не завершился успешно, адрес не считается рабочим.
4. Публичные username бота и поддержки задаются в `web/config.js`. Секретный токен находится только в домашнем `.env`.
5. Бот, база и рабочий Mini App остаются на домашнем ПК. Для кабинета нужен HTTPS-адрес домашнего backend; платный домен для первого теста не требуется.

На GitHub Pages пока размещается демонстрация с отключёнными продажами. Правила GitHub не разрешают использовать Pages как бесплатный хостинг коммерческого SaaS или магазина; перед открытием продаж коммерческая витрина переезжает на подходящий хостинг. Исходники могут оставаться на GitHub.

## Проверки

```bash
PYTHONPATH=backend python -m pytest backend/tests -q
```

Проверяются подпись и срок Telegram initData, чужой доступ, платежи и дубли, сумма/валюта, отдельная выдача заказов, продление, истечение, отзыв и состояние возврата. Прогоны не обращаются к Telegram и провайдерам. Сборка Docker и реальная доставка сообщений требуют проверки на CORE.

Резервирование: ежедневно снимайте согласованную копию SQLite через штатный backup API (не копируйте активный файл без WAL), шифруйте копию и проверяйте восстановление. Инструкция по провайдерам: `docs/SERVERS.md`.
