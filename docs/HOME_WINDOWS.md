# Luna VPN: GitHub Pages и домашний Windows-сервер

Сайт для просмотра дизайна размещается на бесплатном адресе GitHub Pages. Telegram-бот, база и рабочий кабинет Mini App работают на домашнем ПК. Для этого варианта Docker Desktop не требуется.

## 1. Скачать и распаковать

Полный проект:
https://chatgpt.com/library?file_id=libfile_7bc16e1a03348191ada036c891ab20cc&account_id=personal

Распакуйте `luna-vpn` в `C:\Projects`. Рядом должны находиться `INSTALL_WINDOWS.cmd`, `START_LUNA.cmd`, `README.md`, папки `backend`, `scripts` и `web`.

Используйте обновлённый полный архив. Отдельный старый `LUNA_First_Bot.zip` для этих шагов не нужен.

## 2. Установить Python

Если Python уже есть, проверьте в PowerShell:

```powershell
py -3 --version
```

Требуется Python 3.12 или новее. Если команды нет, установите 64-битный Python с официального сайта:
https://www.python.org/downloads/windows/

В классическом установщике включите Python Launcher и `Add python.exe to PATH`. После установки заново откройте PowerShell. Внешние Python-библиотеки установит следующий шаг.

## 3. Создать бота и заполнить настройки

В официальном https://t.me/BotFather отправьте `/newbot`. Имя — `Luna VPN`, username — свободный с окончанием `bot`. Токен сохраните на компьютере.

Дважды нажмите `INSTALL_WINDOWS.cmd`. Он создаст отдельную среду `.venv`, установит зависимости и откроет `.env` в Блокноте. Существующий `.env` не перезаписывается.

Заполните две строки:

```dotenv
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
SUPPORT_USERNAME=ВАШ_USERNAME_БЕЗ_СОБАЧКИ
```

`ADMIN_IDS` и `MINI_APP_URL` на первом запуске оставьте пустыми. Сохраните остальные строки, в том числе `SALES_ENABLED=false`. База нового домашнего запуска будет храниться в `data/luna.sqlite3` рядом с исходниками. Токен не помещается в сайт и не публикуется на GitHub.

В `web/config.js` укажите публичные username без `@`:

```javascript
window.LUNA_CONFIG = {
  botUsername: 'username_вашего_бота',
  supportUsername: 'ваш_username',
  apiBase: ''
};
```

Этот файл не содержит секретов. В версии сайта на GitHub те же публичные имена позволяют открыть бота и поддержку. `apiBase` остаётся пустым: рабочий кабинет обслуживается домашним backend, на одном с ним адресе.

## 4. Запустить

Дважды нажмите `START_LUNA.cmd`. Одно окно запускает backend и бота. Дождитесь `LUNA is running` и сообщения о старте бота. Окно оставьте открытым.

В Telegram отправьте своему боту `/start`, затем `/id`. Полученный числовой ID внесите в `.env`:

```dotenv
ADMIN_IDS=ВАШ_ЧИСЛОВОЙ_ID
```

Пока можно проверить меню и поддержку. Покупка должна сообщать, что продажи не открыты.

Проверка backend в PowerShell:

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/api/health'
```

Ожидается `ok: True`. Дизайн кабинета на этом компьютере доступен по `http://127.0.0.1:8000/app/`. В обычном браузере это демо; авторизация работает через кнопку Telegram.

Если раньше запускали эту же сборку через Docker, сначала остановите её командой `docker compose stop`, чтобы не запускать два бота с одним токеном. База Docker находится в отдельном томе: при необходимости переноса подписок сначала сделайте её резервную копию. Самостоятельное копирование архива исходников базу не переносит.

## 5. Подключить рабочий Mini App

Для телефона нужен публичный HTTPS-адрес домашнего backend. Для первого теста используем временный Cloudflare Tunnel: свой домен, аккаунт Cloudflare и открытие портов роутера не требуются.

Официальная загрузка:
https://developers.cloudflare.com/tunnel/downloads/

Windows → Executable → 64-bit. Создайте `C:\Tools` и сохраните файл как `C:\Tools\cloudflared.exe`.

В отдельном PowerShell:

```powershell
& 'C:\Tools\cloudflared.exe' tunnel --url http://127.0.0.1:8000
```

Окно оставьте открытым. Скопируйте напечатанный HTTPS-адрес `trycloudflare.com`, затем в `.env` задайте его с окончанием `/app/`:

```dotenv
MINI_APP_URL=https://ВАШ-АДРЕС.trycloudflare.com/app/
```

Это шаблон: нужен адрес именно из вашего окна. `ALLOWED_ORIGINS` оставьте пустым, поскольку рабочий кабинет и API находятся на одном адресе.

В окне Luna нажмите `Ctrl+C`, дождитесь остановки и снова запустите `START_LUNA.cmd`. Перезапуск применяет изменения `.env`.

Отправьте боту `/start`, нажмите «Открыть кабинет» или «Кабинет» в меню. Для нового пользователя правильный результат — «ЛИЧНЫЙ КАБИНЕТ» и «Подписки пока нет».

Mini App открывается внутри Telegram. Подключение к VPN позже выполняется в Happ / Incy; рабочий VPN-профиль предоставит выбранный поставщик.

## 6. Опубликовать сайт на GitHub Pages

Репозиторий: https://github.com/appletube8-dotcom/Luna-vpn

Файлы исходников публикуются в этом репозитории. При скачивании выбирайте Code → Download ZIP и распаковывайте папку, где лежит `START_LUNA.cmd`.

В корень репозитория загружается содержимое полной папки `luna-vpn`, включая `web/` и `.github/workflows/pages.yml`. Базу, `.env` и `.venv` загружать не нужно. Для ручной загрузки выбирайте только исходники из чистого архива, до заполнения `.env`.

Settings → Pages → Source → GitHub Actions. Ветка — `main`. Workflow публикует только папку `web/`; ни бот, ни его база на GitHub не запускаются. В Actions дождитесь успешного `LUNA website`, затем скопируйте фактический адрес из Settings → Pages → Visit site. Адрес нельзя считать рабочим до успешной публикации.

В GitHub Pages пока размещается просмотр проекта с отключёнными продажами. Рабочий кабинет и API остаются дома. По правилам GitHub Pages нельзя использовать как бесплатный хостинг коммерческого SaaS или магазина: перед открытием продаж коммерческую витрину перенесём на подходящий хостинг. Исходники при этом могут оставаться на GitHub.

## 7. Обычная работа и резервная копия

Запуск: `START_LUNA.cmd`. Остановка: `Ctrl+C` в окне Luna. После изменения `.env` остановите и запустите Luna заново. Компьютер и интернет должны работать, сон ПК останавливает обслуживание.

После нового запуска cloudflared адрес может измениться. Обновите `MINI_APP_URL`, перезапустите Luna, отправьте `/start` и используйте новую кнопку кабинета. Временный туннель предназначен для теста; постоянный HTTPS-адрес настроим отдельно.

Пока продаж нет, для простой резервной копии остановите Luna и скопируйте папку `data` вместе с приватной копией `.env`. Остановка перед копированием обязательна. Эти файлы не загружаются в публичный GitHub.

После получения реальной VPN-ссылки администратор может выдать доступ в личном чате бота:

```text
/grant ВАШ_ЧИСЛОВОЙ_ID 1 https://ВАША_РЕАЛЬНАЯ_ССЫЛКА_ПОДПИСКИ
```

Это срок на один день для проверки. Сначала создайте соответствующий доступ у поставщика. Команда хранит готовую ссылку; она сама не создаёт VPN и не меняет лимиты на стороне поставщика. При отзыве удаляйте ключ также у поставщика.

## Проверка сборки

Проверяются существующие тесты backend, загрузка `.env`, совместимость путей и HTTP-запуск backend без Telegram. Запуск `.cmd` на реальном Windows и взаимодействие с реальным токеном требуют первого запуска на вашем ПК. Включение GitHub Pages и первый успешный workflow проверяются отдельно.
