# Один продукт, общая система

Сайт и Telegram Mini App — два интерфейса одной системы. Бот — отдельный Python-процесс на CORE. CORE хранит пользователей, заказы и сроки; VPN-панель хранит профили и управляет узлами. Пользователь импортирует ссылку в Happ / Incy. Его VPN-трафик идёт через VPN-узел, не через GitHub Pages или Mini App.

Первый комплект использует ручную выдачу профиля. Для автоматизации потребуется отдельная интеграция с API выбранной панели: создание пользователя, безопасная выдача ссылки, продление и отзыв, идемпотентные фоновые задачи, синхронизация фактического срока. Простой показ срока в боте не обеспечивает его применение в узле.

Статический сайт можно разместить на GitHub Pages или другом хостинге. Mini App можно обслуживать теми же файлами с HTTPS. Бот и база размещаются на CORE. Совместное размещение CORE и VPN-выхода допускается для экспериментов, но ухудшает изоляцию и восстановление; рекомендуются отдельные машины.

PWA использует оболочку сайта, отдельный нативный VPN-клиент не создаётся. Для собственного приложения с системным VPN потребуются нативная интеграция VPN-расширения iOS/Android, разработка, подпись и проверки магазинов. Обычная упаковка сайта в WebView этого не решает.

Private — будущий групповой продукт: отдельные пользователи, приглашения, общий плательщик. Он не реализован в коде первого бота. Локальная сеть и выделенный узел для группы — самостоятельные функции. Мультибрендовая модель потребует brand_id/tenant_id, изоляции прав и распределения затрат; текущая база — для одного бренда LUNA.
